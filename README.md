# sacrificioPage

Sitio estático preparado para publicarse con **GitHub Pages**.

## Contenido

- `index.html`: página principal del sitio
- `.github/workflows/deploy-pages.yml`: workflow de GitHub Actions para desplegar en GitHub Pages

## Despliegue

El repositorio está configurado para desplegar automáticamente en **GitHub Pages** cuando hay cambios en la rama `main`.

También se puede ejecutar manualmente desde la pestaña **Actions** en GitHub.

## Desarrollo

Este proyecto no requiere build ni dependencias externas para funcionar.

Para probarlo localmente, abre `index.html` en tu navegador.
